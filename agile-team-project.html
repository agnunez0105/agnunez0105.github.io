Project Overview

The Employee Health Manager Dashboard is a JavaFX-based desktop application designed for managers to monitor real-time and historical employee health metrics. The application tracks BPM, readiness scores, and daily step counts using a local SQLite database.

This project was developed as part of a collaborative Agile software engineering effort. The goal was to create a centralized dashboard that helps managers view employee health data clearly and efficiently.

Problem

Managers need a centralized way to review employee health information and identify patterns across real-time and historical data. Without a dashboard, health metrics can be harder to monitor, compare, and act on efficiently.

  • Employee health data needed to be visible in one place.
  • Managers needed filtering tools to identify concerning trends.
  • The application needed persistent data storage across sessions.
  • The interface needed to stay responsive while working with database operations.

Technical Direction

The application was built with JavaFX and used SQLite for local data persistence. The architecture used a DAO pattern to separate database access from application logic, making the system more modular and maintainable.

Key Features

  • Centralized dashboard using a TableView
  • Filtering by employee name and health thresholds
  • SQLite database for persistent historical health data
  • Background processing for smoother UI performance
  • Dedicated windows and controllers for adding employees and recording metrics

Tech Stack

  • Java 17+
  • JavaFX
  • SQLite
  • JDBC
  • DAO architecture
  • Git / GitLab
  • Agile / Scrum
