Project Overview

The Employee Health Manager Dashboard is a JavaFX-based desktop application designed for managers to monitor real-time and historical employee health metrics. The system integrates MQTT communication, SQLite database management, Docker containerization, and wearable device simulation.

This project was developed as part of a collaborative Agile software engineering effort focused on building a centralized dashboard for viewing employee health data clearly and efficiently.

Problem

Managers need a centralized way to review employee health information and identify patterns across real-time and historical data. Without a dashboard, health metrics can become difficult to monitor, compare, and act on efficiently.

  • Employee health data needed to be visible in one place
  • Managers needed filtering tools to identify concerning trends
  • The application needed persistent data storage across sessions
  • The interface needed to stay responsive while working with database operations
  • WearOS device communication needed MQTT integration support

Architecture

The project was built using JavaFX for the user interface, SQLite for local persistence, Docker for MQTT infrastructure deployment, and simulated WearOS devices for health metric communication.
