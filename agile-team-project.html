Project Overview

This was a collaborative software engineering project completed using Agile development practices. The project focused on building a Manager Dashboard application to support employee management, scheduling, and workflow organization.

Problem

Managers often need a centralized system to view employee information, manage schedules, and complete administrative tasks efficiently. The challenge was to create a dashboard that made those workflows easier to access and understand.

Role & Contributions

  • Participated in sprint planning and Agile workflows
  • Collaborated on feature development and debugging
  • Worked with Git and version control practices
  • Contributed to dashboard interface functionality
  • Supported software documentation and testing

Process

The team worked through iterative development cycles, using task planning, version control, and testing to refine the dashboard. We focused on building features that were understandable, functional, and useful for a manager-facing workflow.

Skills Used

  • Java
  • JavaFX
  • Git / GitLab
  • Agile / Scrum
  • UI development
  • Team collaboration

Outcome

The final project strengthened my experience working in a shared codebase, contributing to a team-based software application, and communicating through Agile development practices. It also helped me better understand how software design decisions affect usability and workflow clarity.
