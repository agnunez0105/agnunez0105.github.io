Project Overview

This project focused on implementing core data structures and understanding how structure choice affects performance, memory use, and overall program efficiency.

Problem

Many software systems rely on choosing the correct data structure for the task. The challenge was to understand how each structure works, when it should be used, and how it affects runtime and scalability.

Structures Studied

  • Linked lists
  • Stacks
  • Queues
  • Trees
  • Hash-based structures

Skills Used

  • Java
  • Big-O analysis
  • Algorithmic thinking
  • Testing and debugging
  • Performance comparison

Outcome

This project strengthened my understanding of how software works at a deeper level. It helped me think beyond whether code works and focus more on whether it is efficient, scalable, and appropriate for the problem.
