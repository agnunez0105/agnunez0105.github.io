Project Overview

This project represents a collection of Java applications built through coursework. These applications focused on object-oriented programming, modular design, input validation, exception handling, and file-based data processing.

Problem

The goal was to build programs that were not only functional, but also organized, readable, and easier to maintain. Each application required clear structure and careful handling of user input and program errors.

Skills Used

  • Java
  • Object-oriented programming
  • Modular class design
  • Exception handling
  • Input validation
  • File I/O

Outcome

These projects strengthened my ability to write organized and maintainable code. They also helped me understand how strong software structure supports reliability, which is important in both software development and cybersecurity.
